# GY-30 / BH1750 外壳尺寸（mm）

坐标：板中心为原点；**顶边 = 长度方向短边（X−）**；感光面 +Z。

| 项 | 值 |
|---|---|
| PCB | 32.6 × 15.1 |
| 板 + 芯片厚度 | **3.0** |
| 含针总高 | 11.2 |
| 芯片中心 | X = −16.3 + 12 = **−4.3**，Y = 0 |
| 左右托板 | 内壁各突出 **1.0**，顶面高 **8.0**（针脚落在托板之间） |
| 感光孔 | **Ø6**，上壳顶面，对准芯片。顶厚 **0.75**（原 1.5，减半） |
| 走线槽 | **宽 6**，短边（顶边/芯片一端）。下壳从沿口向下开口，上盖从裙边底向上开口；合盖后对准板面高度（Z = 9.8） |
| 固定耳 | 两端以 M3 孔为圆心的半圆，半径 = 板宽/2（约 **9.45**）；孔心距体外沿 **10**，各 1× **M3 Ø3.2** |
| 配合 | 上壳套下壳，左右长边互配波浪（幅 0.42、2 周期），合盖间隙 0.12；其余单边间隙 0.35 |

装配：PCB 放入下壳 → 线落入顶边槽 → 上盖槽口从线上滑下套紧。封闭圆孔无法这样盖。
