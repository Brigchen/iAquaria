# 密封圈

环状密封圈，切面中间低、两边高，底面平整。两边厚 **3 mm**，直径 **72 mm** 处最低厚 **2 mm**。

| 件 | 内径 | 外径 | STL |
|---|---|---|---|
| A | 68.5 | 75.5 | `stl/SealRing.stl` |
| B | 68.75 | 75.25 | `stl/SealRing_68.75.stl` |

帽形密封件：椭圆底 **22×11**；内腔 **10×5**、底孔 **8×4** 不变；帽壁向外加厚至 **1.6 mm**（外廓 13.2×8.2）。打印件 `stl/SealCap.stl`。
