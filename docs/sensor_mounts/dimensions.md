## 7. 装配顺序（穿壁）

1. `DrillGuide` 贴玻璃标记 → 钻 4×Ø4.2 + 1×Ø6 + 2×Ø12 + 1×Ø12.5。  
2. 玻璃两面清洁，贴密封槽硅胶。  
3. 内板（湿）→ 玻璃 → 外板（干），M4×45 对角拧紧 **2 N·m** 量级，勿爆玻璃。  
4. 探头 / PG7 从缸内穿出，锁母 + O 圈。  
5. DS18 先穿 `Gland_Ring` + 法兰，再锁 M10 螺母。
