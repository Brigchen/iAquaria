# 单 TDS 缸沿支架（单独测量）

与四孔支架相同的 **H 夹** 和双横板导向；只开 **Ø10** TDS 孔。**1×M8** 居中顶紧，沿缸沿收到最窄。

| 项 | mm |
|---|---|
| 横板 | **21.8 × 18 × 5** |
| 上横板底 | Z=**20** |
| 下横板顶 | Z=**−140** |
| 总高 | **170**（上横板顶 Z=25 → 下横板底 Z=−145） |
| TDS 孔 | **Ø10.2**（名义 Ø10），X=**−13.9**，Y=0 |
| 内外竖板 | 厚 **6** |
| H 槽 | 12（≤10 mm 玻璃） |
| 1×M8 | M8×1.25 内螺纹，大径 **8.5**，牙底 **7.15**，Y=0，Z=−20，贯通 6 mm 外竖板 |
| 游离倒角 | 直径 **10**（上下横板缸内端、外竖板底端）；与竖板/横档相连的角不倒 |

打印件：`stl/TdsH_Bracket.stl`。
