# iAqua 自动喂食器

对接现有固件：**GPIO27 → 继电器 IN1，低电平吸合，默认 800 ms 脉冲**。不加第二块 MCU、不用步进驱动。Web / App / 云端都走 `{"cmd":"feed","ms":800}`，机械必须「通电转一下、断电停」，一份脉冲 = 一份粮。

| 项 | 值 |
|---|---|
| 控制脚 | `PIN_RELAY_FEEDER` = GPIO27 |
| 默认脉宽 | `ctrl.feeder.pulse_ms` = 800（钳位 100–5000） |
| 机构 | 8 格水平定量转盘 + N20 10–15 RPM |
| 负载电源 | 独立 5 V，经继电器 COM–NO，不从 ESP32 5 V 偷电 |

本目录文件：

| 文件 | 用途 |
|---|---|
| `build_feeder.py` | Blender 5.2 参数化建模（1 BU = 1 mm） |
| `iAqua_Feeder.blend` | 爆炸装配场景 |
| `iAqua_Feeder.glb` | 预览用 |
| `stl/*.stl` | 可切片打印件 |

在已打开的 Blender 里：`exec(open(r"...\\docs\\feeder\\build_feeder.py", encoding="utf-8").read())`。

## 1. 为什么是转盘而不是舵机 / 绞龙

固件 `Actuators::feedPulse` 只把继电器合上 `ms` 再断开，GPIO27 **没有 PWM**。舵机要脉宽，步进要驱动板，绞龙在 0.8 s 内难定量。水平 8 格转盘：料斗重力落料 → 转过一格 → 底板偏心孔 → 斜槽入缸。

标定：`θ = 6 · n · t`。`t = 0.8 s`、`n = 12.5 RPM` → `θ = 60°`。8 格是 45°/格，装好后空转测一圈时间，再改 `pulse_ms`（约 600 ms）或把盘改成 6 格。

## 2. 电路（功率侧只出两根线）

继电器线圈已由主板驱动（手册 3.6 / 图 4-5）。喂食器盒内只接触点：

```
独立 5V+ ── PPTC 500mA ── 继电器 IN1 COM
继电器 IN1 NO ──────────── N20 电机 +
独立 5V− ──────────────── N20 电机 −
电机两端并联：1N5819（阴极接 +）∥ 100nF
```

- 继电器 VCC/GND/IN1 保持现状，不要改接线。
- 感性负载必须续流；PPTC 防堵转。
- 全部 GND 与主板共地（触点侧 5 V− 接到系统 GND）。
- **不要**用 ESP32 板载 5 V 给电机供电。

## 4. 打印件

湿区用 **PETG**（不要 PLA）。喷嘴 0.4 mm，层高 0.20 mm，壁 3 周，顶底 5 层；壳体填充 20%，**转盘 / 电机座 / 联轴套 100%**。PETG 240/80 ℃，风扇 30%。轴孔 XY −0.15 mm，打印后手铰。

| STL | 关键尺寸 mm | 姿态 |
|---|---|---|
| `Hopper.stl` | 上口 Ø70，下口 Ø38，高 80，壁 1.6 | 大口朝下 |
| `Lid.stl` | Ø74，高 6，内止口 | 平放 |
| `Housing.stl` | Ø62×42，底板落料孔 Ø9 偏心 16 | 开口朝上 |
| `Disc.stl` | Ø50×8，8×Ø8，节圆 Ø32，中心 D 孔 | 平放、实心 |
| `MotorMount.stl` | N20 12×10 腔 | 贴床 |
| `Chute.stl` | 内 Ø10，长 45，倾 40° | 沿斜面立打 |
| `Clamp.stl` | 开口 8–12，M3 | 开口朝上 |
| `Coupler.stl` | D 轴 Ø3×深 8 | 平放、实心 |

转盘与底板间隙 0.4–0.6 mm；落料孔比格孔大约 1 mm。颗粒建议 3–4 mm。

## 5. 组装

1. 热熔 M3 入壳体；N20 装座，D 轴朝上。
2. 联轴套 + 转盘；手转一圈无刮擦，8 格能对准底板孔。
3. 料斗扣壳体，盖上硅胶圈；倒立不漏料。
4. 电机并二极管与电容，2 芯接到 IN1 **NO** 与电源−。
5. 夹到缸沿，出料槽口距水面 ≥50 mm，避免水汽直喷料口。
6. Web 点喂食，目测默认 800 ms 是否转过一格；改 `ctrl.feeder.pulse_ms` 直到恰好一格。
7. 称 10 次取平均，记入养护日志。

堵转只靠 PPTC + 短脉冲。**不要**把喂食改成常开通道（`ControlEngine` 已跳过 `CH_FEEDER`）。若以后要「一天 n 次」，用 NTP 时钟调 `feedPulse` 即可，硬件不用换。
