# HC-SR04 缸沿支架（倒 L + 整体 H 夹）

坐标系：玻璃在 X=0..8（演示）、**缸沿顶面 Z=0**；缸内 −X。上横板底面 Z=**50**、顶面 Z=54。传感器 **12 mm** 厚，用 2×M3 **固定在横板下面**。

## 上横板

| 项 | 尺寸 mm |
|---|---|
| 外廓 | **34** × 80 × 4，四角倒圆 **Ø10**（R5） |
| 相对缸沿 | 底面 **Z=50**（+5 cm）；缸内伸出 34（较原 42 缩短） |
| 两耳固定孔 | **Ø3.2**（M3），中心 **X = −20**（距内竖板缸内面 **15**），**Y = ±29**（孔距 58） |
| 凹字 | 顶面中央 **iAquaria-JMU**，总长 **50**，深 **1** |

传感器挂在横板下方；声波朝 −Z。

## H 夹（内外竖板同一厚度、同一宽度）

内竖板从夹臂底一通到上横板底，厚 5 mm，不是上下两段。

| 项 | 尺寸 mm |
|---|---|
| 槽宽 | **12**（≤10 mm 玻璃） |
| 内竖板 | 厚 **5**、宽 **50**，Z=−40 → +50 |
| 外竖板 | 厚 **5**、宽 **50**，Z=−40 → +5 |
| 横档 | 厚 **5**，骑在缸沿 |
| 过线口 | 内板顶部 **宽 23 × 高 12**，电缆从板下传感器穿出 |
| 夹臂下垂 | 40 |

## 2×M8 内螺纹（外侧壁）

| 项 | 尺寸 |
|---|---|
| 牙型 | M8×1.25，内螺纹大径 **8.5** |
| 孔位 | Y = **±11**（孔距 22），Z = **−20** |

STL：`stl/M8x1.25x25.stl`。装缸用不锈钢 M8；螺丝与玻璃之间加硅胶垫。
