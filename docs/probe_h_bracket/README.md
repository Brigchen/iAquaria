# 温度 / TDS / pH 缸沿支架

与超声波支架相同的 **H 夹** 骑在缸沿上，外侧两孔为 **M8×1.25 内螺纹**（大径 8.5），螺丝拧入后顶紧玻璃。上横板高出缸沿 **20 mm**；缸内竖板下伸 **140 mm**，末端再一块同孔径横板，把探头上下两点限位。总高 **170 mm**。

孔径：水温 **Ø8**、TDS **Ø10**、pH **Ø30**、pH 补偿温度 **Ø8**（贴 pH）。上下横板 **41.8×70.8 mm**。

尺寸见 [dimensions.md](dimensions.md)。重建：`build_probe_h_bracket.py`。打印件：`stl/ProbeH_Bracket.stl`。
