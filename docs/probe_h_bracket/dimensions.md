# 温度 / TDS / pH 缸沿支架（倒 L + 整体 H 夹）

坐标系：玻璃演示 X=0..8，**缸沿顶面 Z=0**；缸内 −X。上横板底面 Z=**20**（缸沿上 2 cm）；下横板顶面 Z=**−140**（缸内下伸 14 cm）。总高 **170 mm**（上顶到下底）。

横板伸入缸内按 **Ø30** 收到最窄；沿缸沿随孔径加宽，四孔：水温、TDS、pH、pH 补偿温度（贴 pH）。

H 夹：槽宽 12（≤10 mm 玻璃），外侧 **2×M8**。

| 项 | 尺寸 mm |

| 外廓 | **41.8 × 70.8 × 5**，游离端两角倒圆 **Ø10**（R5；靠竖板的角不倒） |
| 上横板 | 底面 Z=**20** |
| 下横板 | 顶面 Z=**−140** |

探头从上横板穿入，由下横板第二孔导向，保持竖直。
