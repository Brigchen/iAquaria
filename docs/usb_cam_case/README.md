# USB 摄像头外壳

**镜头 +Z 朝前**。外形 **50 × 50 × 30 mm**（含后盖）。物理顶 **+Y** 阿卡（上宽 50 / 根部 38）。物理底 **−Y** 是 Type-C，经出线槽直连板下 PH2.0。

内腔按 `Cam_module` 留 **单边 0.2 mm**。壁厚 **2.0 mm**。PCB 由四角 **Ø6** 连接柱托住，柱上 **Ø2.6** 孔对准板角孔，M2 螺丝从后腔固定。后盖 **50 × 50 × 2**，四角不打孔。

打印件：`stl/CamCase_Body.stl`、`stl/CamCase_Back.stl`、`stl/CamCase_Arca.stl`。模块物体不在这些 STL 里。
