# USB 摄像头外壳尺寸（mm）

**朝向**：镜头 **+Z 朝前**；物理 **顶 +Y**（阿卡）；物理 **底 −Y**（Type-C）。PCB 中心为原点。1 BU = 1 mm。壳体只包住 `Cam_module`，不改模块。

| 项 | 值 |
|---|---|
| 外形 | **50 × 50 × 30**（含后盖，后盖在 −Z） |
| PCB 内腔 | **32.4 × 32.4**（板 32，单边间隙 **0.2**） |
| 拔模 | 侧壁 **1°**，后口略大，朝镜头收 |
| 壁厚 | **2.0**；Type-C 凹台处剩余 **≥ 1.6** |
| 前孔 | **Ø14.4**（镜头 Ø14 + 单边 0.2），内壁在镜头座方台之前 0.2 |
| PCB 固定 | 四角连接柱 **Ø6**，顶到板下；对应板角孔 **Ø2.2** 处开 **Ø2.6** 通孔，M2 螺丝从后腔拧入 |
| 板后 | 内底在 PH2.0 插座之后 **0.2**（z = −7.8） |
| 出线槽 | **−Y** 侧壁，从插座通到 Type-C，槽底不切穿后壁 |
| Type-C | **−Y**，中心 z = **−4.6**；开孔与法兰各加单边 0.2；M2 孔 **Ø2.6**，距 **16**，只在主壳 |
| 后盖 | **50 × 50 × 2**，定位凸台避开 PH2.0；四角不打孔 |
| 外圆角 / 内圆角 | **R0.8** / **R0.5** |
| 阿卡 | **+Y**；上宽 **50**、根部 **38**、45°、榫高 **6**、总高 **10**；Z 与壳体前后齐 |
