## 2. 电源架构

| 电源轨 | 来源 | 负载 |
|---|---|---|
| 12V | 适配器（≥2A） | CO2 电磁阀；DC-DC 输入；（可选）灯光/加热棒经继电器触点 |
| 5V | DC-DC 降压（≥2A） | 继电器板 VCC、HC-SR04 VCC、RS485 适配器 VCC、（多数 485 模块 VCC） |
| 3.3V | ESP32 板载 LDO | DS18B20、GY-30、MOS 模块控制侧 VCC、ECHO 分压后 |

要点：
- **所有 GND 必须共地**（12V/5V/3.3V/485 模块）。
- ESP32 由 USB 或 5V 接 5V 引脚供电均可；调试期建议接 USB（兼串口日志）。
- 电磁阀为感性负载：MOS 输出端并联续流二极管（1N4007，负极接 12V 正端）。

## 3. 分组件接线表

### 3.1 RS485 总线（TDS/EC + pH/ORP）

TDS 是两块板，不能把第一块测量板直接接到 ESP32。

| 板 | 接口 | 接法 |
|---|---|---|
| 测量板 | TXD、RXD、GND、VCC | 接两只带温度校正的 TDS 探头。这是 TTL 串口，不是 485 |
| TTL 转 485 板 | 输入 VCC、GND、TXD、RXD | 测量板 TXD 接本板 RXD，测量板 RXD 接本板 TXD；VCC、GND 各自相连。原配排线若按同名直连，保持原排线 |
| TTL 转 485 板 | 输出 +5V、A、B、GND | A/B 上总线。+5V 只为本板供电，不从 A/B 取电，也不拿去供 ESP32 |

测量板的 TXD 多为 5 V。ESP32 的 GPIO 不是 5 V 电平，直连可能损坏 GPIO16。固件只有一路 UART1，TDS 与 pH 必须挂在同一条 A/B 上；测量板若占用 GPIO16/17，pH 变送器就无法接入。因此正常安装一定是：测量板 → TTL 转 485 → 总线 A/B → 主板侧 485 转 TTL → ESP32。

主板侧 485 转 TTL 的丝印为 **VCC、TXD、RXD、GND**，没有 DI、RO、DE。收发方向由模块硬件自动切换，GPIO4 不接线。

| 模块丝印 | ESP32 | 说明 |
|---|---|---|
| RXD | GPIO17（TX） | 主板发送，交叉接到模块 RXD |
| TXD | GPIO16（RX） | 模块发送，交叉接到主板 RX |
| VCC | 5V | 模块允许 3.3～5 V 时也可接 3.3 V |
| GND | GND | 必须与主板共地 |

| 总线 | 设备 |
|---|---|
| A(+) / B(-) | TDS 模块 A/B（实测地址 2）、pH/ORP 模块 A/B（目标地址 3）**并联** |
| 屏蔽层 | 单点接 GND（长线 >5m 建议 A/B 两端 120Ω 终端电阻） |

**地址冲突处理**：TDS 模块实测出厂地址为 02。首次接线时**只接 pH/ORP 模块**，按厂家手册用 Modbus 写寄存器把地址改为 **03**（或用 USB-RS485 + 串口工具改），然后全部接入。改错也不怕：在 Web「RS485 从机」页把 `regs.ph.addr` 改成实际地址即可读通。

### 3.2 DS18B20（红黄黑三线）
| 线色 | 接法 |
|---|---|
| 红 | 3.3V |
| 黄 | GPIO13 + **4.7kΩ 上拉到 3.3V**（探头与上拉电阻之间距离不限） |
| 黑 | GND |

多探头可并联在同一条总线上（固件自动取第 1 个）。

### 3.3 HC-SR04（5V 供电）
| 引脚 | 接法 |
|---|---|
| VCC | 5V |
| TRIG | GPIO25 |
| ECHO | **1kΩ 串联后接 GPIO26**，GPIO26 再经 **2kΩ 下拉到 GND**（5V→3.3V 分压，防烧口） |
| GND | GND |

探头垂直朝下安装在缸顶，量程 20~4500mm；`ctrl.level.mm_empty/mm_full` 两点标定 0%/100%。

### 3.4 GY-30 光照度（BH1750，I2C，5 排针）
| 引脚 | 接法 |
|---|---|
| VCC | 3.3V（或 5V，模块板载 LDO 兼容） |
| GND | GND |
| SCL | GPIO22 |
| SDA | GPIO21（硬件 I2C 默认脚；模块板载上拉，无需外接电阻） |
| ADO | 悬空或接 GND（I2C 地址 0x23）；接 VCC 则为 0x5C |

### 3.5 MOS 模块（红色小板：SIG/VCC/GND + VIN/GND 双孔）
| 位置 | 接法 |
|---|---|
| SIG | GPIO33（高电平导通） |
| VCC / GND | 3.3V / GND（控制侧，光耦隔离供电） |
| VIN(+)/GND(V-) | 12V+ / 接电磁阀一端；电磁阀另一端回 12V-（负极回路共用 GND） |

上电默认全断（GPIO33 低电平）；CO2 电磁阀只有「开/关」两态，无需 PWM。

### 3.6 4 路继电器 MK001268（5V，低电平触发）
| 继电器板 | ESP32 | 通道 |
|---|---|---|
| VCC | 5V | — |
| GND | GND | — |
| IN1 | GPIO27 | 喂食器 |
| IN2 | GPIO14 | 水族灯 |
| IN3 | GPIO32 | 加热棒 |
| IN4 | GPIO5 | 补水泵（低电平触发；**须 10kΩ 上拉到 3.3V**，手册 4.7） |

- 触点侧：电源+ → COM，NO → 负载+（手册图 4-5）。
- 低电平触发：固件上电先拉高 = 全断。GPIO5 为 strapping，缺 10kΩ 上拉可能上电误吸合。

### 3.7 TF 卡扩展（可选，SPI，非默认 VSPI）
| TF 模块 | ESP32 | 说明 |
|---|---|---|
| VCC | 5V 或 3.3V | 按模块 |
| GND | GND | 共地 |
| SCK | GPIO18 | 时钟 |
| MOSI | GPIO19 | 主板 → 卡 |
| MISO | GPIO34 | 卡 → 主板（仅输入；模块侧建议 10kΩ 上拉到 3.3V） |
| CS | GPIO23 | 片选 |

GPIO5 已给补水泵，不能当 CS。接线与常见 VSPI 例程（5/18/19/23）不同。

## 4. Strapping 引脚警告（经典 ESP32）

| 引脚 | 属性 | 本项目用法 |
|---|---|---|
| GPIO0/2/12/15 | strapping | 空置不接负载（GPIO12 上电拉高会导致 flash 电压错配） |
| GPIO5 | strapping | 补水泵 IN4，**10kΩ 上拉 3.3V** |
| GPIO6-11 | 内部 flash | 严禁外接 |
| GPIO1/3 | UART0 | USB 串口日志保留 |

## 5. 上电自检清单（分步）

1. **只接 ESP32 + USB**：看串口 115200，应有 `iAqua v0.1.0 启动`；未配 WiFi 时自动开 AP `iAqua-Setup/12345678`。
2. 手机连 AP → `http://192.168.4.1`：能看到仪表盘即 Web/WS 正常。WiFi 页填家里 2.4G SSID/密码保存，设备重启联网。
3. 接 DS18B20：日志 `DS18B20 就绪，探测到 1 个探头`，仪表盘水温出现。
4. 接 HC-SR04：仪表盘水位出现，手挡探头数值变化。
5. 接 GY-30：日志 `BH1750 就绪 addr=0x23`，仪表盘光照度出现；手遮探头数值骤降。
6. 接 485 适配器 + TDS（地址 **2**）：日志 `tds@2`；无响应则检查 A/B、共地。
7. 接 pH/ORP（地址 **3**）：仪表盘 pH/ORP 出现；水温用 DS18B20。
8. 继电器：Web 控制页逐路点「开/关」，听吸合声、量触点。
9. MOS + CO2 电磁阀：手动开阀听「咔哒」进气声。
10. 全部通过后恢复自动模式运行 72h，观察日志无重启（uptime 持续增长）。

## 6. 常见问题

| 现象 | 排查 |
|---|---|
| 485 全部无响应 | A/B 接反（最常见）；TXD/RXD 接成同名直连；未共地；VCC 不足 |
| 单个 485 设备无响应 | 地址不对（`regs.*.addr` 改）；该设备 9600 8N1 不符（部分模块默认 4800） |
| DS18B20 恒 85℃ | 上电未完成转换就读（固件已处理）；上拉缺失；探头进水短路 |
| 水位跳变 | 探头下方有泡沫/水流干扰；重新标定 mm_empty/mm_full |
| WiFi 连不上 | 只支持 2.4GHz；密码错误；信号弱（仪表盘看 RSSI） |
| 日志提示"未探测到 BH1750" | SDA/SCL 接反；SDA 缺上拉电阻；GY-30 的 ADO 接了 VCC（此时固件会自动试 0x5C，仍不通再查接线） |
| 光照读数封顶不变 | 阳光直射超量程（BH1750 高分辨率模式上限约 5.4 万 lx），属正常现象 |
| 继电器上电全吸一下再断 | 正常范围外的板子需 IN 上拉 10kΩ 到 5V（本项目板低电平触发，上电高即断开） |
